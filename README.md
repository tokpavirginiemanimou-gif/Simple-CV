# CV en HTML


Ce projet consiste en la création de mon curriculum vitae (CV) en utilisant uniquement le langage HTML.

Il s'inscrit dans mon apprentissage du développement front-end, avec pour objectif de maîtriser les bases de la structuration d'une page web.

## Objectifs
- Comprendre la structure HTML
- Organiser des informations de manière claire
- Créer une page web simple et lisible
- Mettre en pratique les balises HTML de base

## Contenu du CV
- Informations personnelles
- Formation académique
- Compétences techniques
- Expériences professionnelles
- Langues
- Centres d'intérêt

## Technologies utilisées
- HTML5

## Améliorations futures
- Ajouter du CSS pour améliorer le design
- Rendre la page plus moderne
- Ajouter une version responsive
